Semantic rules

  • Backgrounds: page off_white → surface white → accent primary_bg. Separation comes from contrast, not shadows.
  • Text: body black · secondary medium_gray · muted/disabled/empty inactive · error error · inverse white.
  • Interaction: active/selected is always primary. Unselected brand is primary_inactive — never an opacity.
  • Status is a light fill + matching dark ink (+ optional 1px border of the dark ink).
  • Macro colors are reserved — only ever encode P → C → F, never decoration.
  • Import the token, never the hex. 81 files import @/theme; 13 files still use literals.

Rules

  • Always render text through H1…H6. Only 3 files import RN Text; just 9 inline fontSize values exist app-wide.
  • Never set fontFamily outside the theme. Today it appears in exactly one file — keep it that way.
  • Recolor, never resize. style={{ color: colors.medium_gray }} is the pattern; sizes and weights come from the scale.
  • props.style merges after the token, so a passed color wins — that is how variants are built.
  • lineHeight is set in exactly one place. Multi-line body copy should get 1.3–1.4 × fontSize until a token exists.

Canvas typography duplicate

Rules

  • Gutter: screen content uses paddingHorizontal: 20 — the single most common padding (19 sites).
  • Card padding: 16 for content cards, 12 for compact cards/rows.
  • Prefer gap over margin. Margin is reserved for one-sided nudges.
  • Section spacing: marginBottom: 20; end-of-list paddingBottom: 40 to clear the centre FAB.
  • Off-scale values (5, 7, 9, 13, 14, 18, 28, 35) are local optical fixes — don't promote them.

Iconography

  • Colored through the color prop because the sources stroke currentColor. A few legacy assets hardcode their own colors and ignore it.

  • Active = primary, inactive = inactive.

08

Patterns & conventions

Do

  • Import colors from @/theme; render text with H1…H6.
  • Page off_white → surface white → accent primary_bg → active primary.
  • Compose with gap (8 / 12 / 20); pad cards 16, screens 20.
  • Radius 8 for surfaces, 10 for large controls, 50 for circles.
  • Keep cards flat; use the canonical shadow only for floating chrome.
  • Space list items with ItemSeparatorComponent, not margins.
  • Macro colors, always P → C → F.
  • Reserve ~40px bottom clearance on tab screens so the FAB never covers content.

Don't

  • Hardcode hex / rgba / color names, fontSize, fontFamily or fontWeight.
  • Invent a radius, shadow or height without checking §4 and §5.
  • Nest a shadowed card inside another shadowed card.
  • Set a fixed width on text that should wrap — three cards hardcode 240.
  • Copy ModalCore backdrops, sheet handles or macro bands; extract them.
  • Build a fifth nav strip — the existing four already disagree.
  • Use colors.error for active indicators; it's a semantic error token.
